# TravelMatch 🧭

ระบบแนะนำสถานที่ท่องเที่ยวที่เหมาะสมกับงบประมาณ ระยะเวลา และความสนใจของผู้ใช้
พัฒนาด้วย Python + Pandas + NumPy + Streamlit ตามที่ระบุในบทที่ 3 ของรายงาน

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | โค้ดหลักของแอปพลิเคชัน (Streamlit) |
| `travel_data.csv` | ชุดข้อมูลสถานที่ท่องเที่ยวตัวอย่าง 50 รายการ (Dataset) |
| `generate_data.py` | สคริปต์ที่ใช้สร้าง `travel_data.csv` (รันซ้ำได้ถ้าต้องการแก้ไขข้อมูล) |
| `requirements.txt` | รายชื่อไลบรารีที่ต้องติดตั้ง |

## วิธีติดตั้งและรัน

```bash
# 1. ติดตั้งไลบรารีที่จำเป็น
pip install -r requirements.txt

# 2. รันแอปพลิเคชัน
streamlit run app.py
```

จากนั้นเบราว์เซอร์จะเปิดขึ้นเองที่ `http://localhost:8501`

## วิธีใช้งาน

1. กรอก **งบประมาณต่อคน**, **ระยะเวลาที่มี (วัน)** และเลือก **ความสนใจ** ในแถบด้านซ้าย
2. กดปุ่ม "ค้นหาสถานที่ที่ใช่สำหรับคุณ"
3. ระบบจะแสดง **Top 5** สถานที่ที่มีคะแนนความเหมาะสมสูงสุด พร้อมคะแนนแยกตามปัจจัย

## หลักการคำนวณ (Weighted Scoring) — ตรงกับบทที่ 3.5 ของรายงาน

ระบบใช้วิธี Weighted Scoring โดยกำหนดน้ำหนักให้กับปัจจัย 4 ด้าน ได้แก่

- ความสนใจ **40%**
- งบประมาณ **30%**
- ระยะเวลา **20%**
- คะแนนรีวิว **10%**

จากนั้นนำคะแนนของแต่ละปัจจัยมาคำนวณเป็นคะแนนรวม แล้วจัดอันดับ (Ranking) สถานที่ท่องเที่ยวตามคะแนนจากมากไปน้อย
(ดูสูตรจริงในฟังก์ชัน `calculate_score()` ของไฟล์ `app.py`)

## Mapping รายงาน ↔ โปรแกรม

| ในรายงาน | ในโปรแกรม |
|---|---|
| Dataset | `travel_data.csv` |
| Data Preparation | `load_data()` (ใช้ Pandas) |
| ปัจจัยความสนใจ 40% | `calculate_interest_score()` |
| ปัจจัยงบประมาณ 30% | `calculate_budget_score()` |
| ปัจจัยระยะเวลา 20% | `calculate_duration_score()` |
| คะแนนรีวิว 10% | `calculate_review_score()` |
| Weighted Scoring | `calculate_score()` |
| Ranking | `sort_values()` ใน `recommend()` |
| ระบบแนะนำ | Top 5 (`TOP_N = 5`) |
| Application | Streamlit (`app.py`) |

## ข้อจำกัดของระบบต้นแบบ (สำหรับบทที่ 4.5)

- ยังไม่มีการเรียนรู้พฤติกรรมผู้ใช้ (Machine Learning) — ใช้สูตรคำนวณคงที่
- ข้อมูลสถานที่เป็นชุดตัวอย่างคงที่ 50 รายการ ยังไม่เชื่อมต่อข้อมูลแบบ Realtime
- ยังไม่มีระบบวางแผนเส้นทางการเดินทางอัตโนมัติ (แนวทางการพัฒนาต่อในอนาคต)
